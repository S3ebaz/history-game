## Cómo publicarlo

1. Entra a tu repositorio (ejemplo: `history-game`).
2. Borra los archivos viejos o duplicados.
3. Sube **estos 4 archivos a la raíz** (no dentro de una carpeta).
4. Ve a **Settings → Pages**.
5. Source: rama `main`, carpeta `/ (root)`.
6. Espera 1-2 minutos.

## El juego

Va desde las culturas prehispánicas hasta el año 2000.
Cada decisión es **buena**, **mixta** o **mala**, suma o resta puntos y al final muestra la lista de acciones.

Uso educativo.
